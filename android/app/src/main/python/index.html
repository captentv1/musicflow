Create an app on developer.spotify.com/dashboard, then add this exact redirect URI:
http://127.0.0.1:5090/auth/spotify/callback
YouTube Loading…
In console.cloud.google.com: enable “YouTube Data API v3”, create an OAuth client ID (Web application), then add this exact redirect URI:
http://127.0.0.1:5090/auth/youtube/callback
Security: MusicFlow never sees or stores your Spotify or Google password. Sign-in happens entirely on the official site (accounts.spotify.com / accounts.google.com) — the app only receives a temporary access token, which you can revoke at any time with “Disconnect” or from your Spotify/Google account security settings. The Client ID/Secret and tokens are stored only locally on this device (config.json file), never sent anywhere else.
