Mes comptes

Connecte tes comptes pour pouvoir créer des playlists directement dessus depuis l'onglet Transférer.

🟢 Spotify Chargement…
Crée une app sur developer.spotify.com/dashboard, puis ajoute cette URI de redirection exacte :
http://127.0.0.1:5090/auth/spotify/callback
🔴 YouTube Chargement…
Dans console.cloud.google.com : active « YouTube Data API v3 », crée un identifiant OAuth (type Application Web), puis ajoute cette URI de redirection exacte :
http://127.0.0.1:5090/auth/youtube/callback
🔒 Sécurité : MusicFlow ne voit et ne stocke jamais ton mot de passe Spotify ou Google. La connexion se fait entièrement sur le site officiel (accounts.spotify.com / accounts.google.com) — l'app ne reçoit qu'un jeton d'accès temporaire, révocable à tout moment via « Déconnecter » ou depuis les paramètres de sécurité de ton compte Spotify/Google. Le Client ID/Secret et les jetons sont stockés uniquement en local sur ce PC (fichier config.json), jamais transmis ailleurs.
