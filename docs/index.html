Your music,
neatly organized.

Search a song, paste a playlist link or pick an artist: MusicFlow downloads everything with the right title, album, cover art and lyrics.

⬇ Android (APK) ⬇ Windows (.exe) Source code

Free · open source (GPL-3.0) · no account, no ads · Android 8+ (64-bit) and Windows 10/11

Features

🔎

Search everywhere

By title, by artist (full discography), by playlist or album link, or many titles at once.

🧭

Discover

Global, per-country and per-genre charts, popular playlists, similar artists.

📥

Download queue

Several playlists in parallel, pause and resume, automatic resume when internet comes back.

🏷️

Clean files

Title, artist, album, genre, track number, year, HD cover art and synced lyrics.

🎯

The right version

Duration check, live and karaoke versions skipped, compare versions, “other version” in one tap.

🧹

No duplicates

What is already in your folder is never downloaded again.

🎚️

Every format

MP3 up to 320 kbps, FLAC, WAV, Opus, AAC. Leading and trailing silence removed.

📚

Library

Favorites, tags, tag editor, automatic re-tagging, shrink big files.

🔔

Follow

Follow a playlist or an artist: new tracks and new releases are detected.

🎨

16 themes

Glass style, light themes, OLED black and automatic — with an interactive tutorial on every screen.

🌙

In the background

Downloads keep going with the app closed and resume on their own after a dropout.

Install

Android

  1. Download MusicFlow.apk.
  2. Open it and allow installing from this source.
  3. Choose your music folder on the first download.

Windows

  1. Download MusicFlow.exe.
  2. Double-click it (if Windows shows “Windows protected your PC”: More info › Run anyway).
  3. MusicFlow opens in your browser. Nothing else to install.
